Cloud save via Dropbox

Legacy Cloud Launcher Sync

Um launcher para abrir o Legacy com sincronizacao automatica do save antes e depois do jogo.

Politica de privacidade

O que o app faz

O Legacy Cloud Launcher Sync conecta a conta Dropbox autorizada pelo usuario e guarda uma copia do save do jogo na pasta do aplicativo dentro do proprio Dropbox do usuario.

Ao clicar em jogar, o launcher verifica a nuvem primeiro. Quando o jogo fecha, ele envia o save atualizado. Isso ajuda a manter o progresso disponivel em outro computador vinculado a mesma conta Dropbox.

Permissoes usadas

  • Ler metadados dos arquivos do app para comparar versoes do save.
  • Ler o save salvo na nuvem quando for preciso restaurar ou atualizar o computador.
  • Enviar o save atualizado para a pasta do app no Dropbox.

Controle do usuario

O acesso pode ser removido dentro do launcher pela opcao de limpar credenciais ou diretamente nas configuracoes da conta Dropbox.
