Politica de privacidade

Legacy Cloud Launcher Sync

Ultima atualizacao: 12 de setembro de 2026

Resumo

O Legacy Cloud Launcher Sync usa a API do Dropbox apenas para sincronizar arquivos de save do jogo na conta Dropbox autorizada pelo proprio usuario.

Dados acessados

O aplicativo acessa somente os arquivos criados por ele dentro da pasta do app no Dropbox do usuario. O app nao solicita acesso completo ao Dropbox.

Como os dados sao usados

Os arquivos de save sao usados para baixar, comparar e enviar o progresso do jogo entre computadores do mesmo usuario. O aplicativo nao vende, compartilha ou utiliza esses dados para publicidade.

Armazenamento

Os saves ficam armazenados na propria conta Dropbox do usuario. O launcher tambem salva localmente um token de acesso protegido pelo Windows para permitir reconexao automatica.

Controle e revogacao

O usuario pode remover as credenciais salvas usando a opcao "Limpar credenciais" no launcher. Tambem pode revogar o acesso do aplicativo nas configuracoes de seguranca da conta Dropbox.

Contato

Para duvidas sobre esta politica, entre em contato com o desenvolvedor do aplicativo.
